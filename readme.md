
# YBYX — Site institucional

Site institucional estático da YBYX.

## Estrutura

- `docs/index.html`: página inicial
- `docs/acesso.html`: seleção entre Área do Cliente e Área Corporativa
- `docs/assets/css/style.css`: identidade visual e responsividade
- `docs/assets/js/main.js`: menu mobile e ano do rodapé

## Publicação no GitHub Pages

Nas configurações do repositório, selecione:

- Source: Deploy from a branch
- Branch: `main`
- Pasta: `/docs`

## Importante

As áreas de cliente e corporativa são apenas páginas de apresentação nesta versão.

Não há autenticação, banco de dados, portal funcional ou painel administrativo implementados.

Não inclua credenciais, tokens, dados pessoais ou segredos neste repositório público.
